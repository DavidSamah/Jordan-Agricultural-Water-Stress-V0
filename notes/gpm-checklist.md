# GPM First-Download Checklist

Before accepting downloaded data:

[ ] File exists
[ ] File size is plausible
[ ] File type is correct
[ ] Dataset name/version is verified
[ ] Date is correct
[ ] Variable is precipitation
[ ] Latitude range includes Jordan
[ ] Longitude range includes Jordan
[ ] Units are identified
[ ] Missing-data value is identified
[ ] No access-error HTML was saved as scientific data

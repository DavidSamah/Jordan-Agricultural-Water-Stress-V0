# Step 45 — Dataset Verification Checklist

For every candidate dataset verify:

## Identity
- official dataset name
- provider
- product/version

## Geographic coverage
- does it cover Jordan?

## Time coverage
- earliest available date
- latest available date

## Spatial resolution
- native pixel/grid size

## Temporal resolution
- hourly/daily/dekadal/16-day/etc.

## Variables
- exact variable needed

## Access
- API?
- download?
- Google Earth Engine?
- authentication required?

## Quality
- QA flags
- missing values
- cloud contamination
- known limitations

## Compatibility
- can it be aggregated/resampled to our common grid?
- can it be aligned to a common time interval?

## Research role
- predictor?
- target?
- validation source?

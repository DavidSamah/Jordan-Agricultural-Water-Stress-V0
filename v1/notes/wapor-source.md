# WaPOR V3 Source Verification

Official source:
FAO WaPOR Version 3

Primary V1 variable:
AETI = Actual Evapotranspiration and Interception

Candidate resolution:
Level 2 = approximately 100 m

Candidate temporal resolution:
Dekadal

Secondary variable:
RET = Reference Evapotranspiration

Authentication:
WaPOR V3 API does not require API key or credentials.

Why it matters:

AETI provides an estimate of actual water consumed by
evaporation + transpiration + interception.

For V1 this helps move from:

environmental stress

toward:

actual agricultural water consumption and deficit.
